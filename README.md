# CMS Page Builder — Инструкция по установке

## Файлы в архиве

```
/
├── index.html        ← Главный файл CMS
└── .htaccess         ← Защита Apache (скрытый файл!)
```

## Установка на хостинг

1. Загрузите `index.html` и `.htaccess` в корень вашего сайта (или в любую папку)
2. Откройте сайт в браузере
3. Войдите через кнопку входа

## Данные для входа

- **Логин:** `schmel25`
- **Пароль:** `schmel25@#$1986`

> Пароль захэширован внутри JS — в коде не хранится открытым текстом.

## Возможности

### Блоки страницы
- 🗂️ Header — шапка с логотипом и навигацией
- 🚀 Hero — главный баннер с кнопкой
- 📝 Текст — заголовок + абзац
- 📊 Колонки — 2 или 3 колонки
- ⭐ Преимущества — 3 карточки
- 📈 Статистика — 4 числа
- 🖼️ Изображение — полноширинный баннер
- 🎨 Галерея — сетка фотографий
- ▶️ Видео — YouTube embed
- 🎯 CTA — призыв к действию
- 💬 Отзывы — 3 карточки с отзывами
- 📧 Контактная форма
- ➖ Разделитель
- ⬜ Отступ
- 📌 Footer — подвал

### Функции редактора
- **Drag & Drop** перетаскивание блоков
- **Live-preview** — изменения отображаются мгновенно
- **Несколько страниц** — создавайте любое количество
- **История** — кнопка "Отменить"
- **Адаптив** — просмотр в режиме ПК / Планшет / Мобильный
- **Экспорт HTML** — скачать готовую страницу
- **Сохранение** — данные хранятся в localStorage браузера

### Настройки каждого блока
- Цвета (фон, текст, акцент)
- Шрифты и размеры
- Отступы
- Контент (тексты, ссылки, изображения)

## Хранение данных

Данные страниц хранятся в `localStorage` браузера — никакой базы данных не нужно!
При очистке кэша браузера данные сбросятся. Используйте **Экспорт HTML** для резервной копии.

## Безопасность .htaccess

Файл `.htaccess` (обратите внимание — он скрытый, начинается с точки):
- Запрещает просмотр директорий
- Блокирует доступ к системным файлам
- Добавляет security headers
- Включает GZIP и кэширование

⚠️ **Важно:** На некоторых хостингах скрытые файлы (начинающиеся с `.`) не видны в файловом менеджере. Включите показ скрытых файлов или загружайте через FTP.
